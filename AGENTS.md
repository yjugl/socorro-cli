# AGENTS.md

This repository keeps its shared project guidance in `CLAUDE.md`. Read that
file completely before making changes; it applies to Codex as well as Claude
Code despite the historical filename.

Machine-local guidance may also exist in `CLAUDE.local.md`. Before starting an
autonomous or multi-agent run, read that file completely and follow its
Autonomous Multi-Agent Workflow. It is deliberately gitignored and may be much
larger than Codex's automatic project-instruction limit, so do not assume this
bootstrap contains or replaces it. If the file is absent, continue with
`CLAUDE.md` alone.
